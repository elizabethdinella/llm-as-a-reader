## Attempt 1

### Explanation
To implement the `Account` constructor, I first initialize a local string variable `name` with `requestedName` and an integer `count` set to `1`. I then use a `while` loop that checks whether `name` is available using the static helper method `isAvailable(name)`. If `isAvailable(name)` returns `false` (meaning the name is unavailable), the loop body executes, updating `name` to `requestedName + count` and incrementing `count` by 1. Once an available username is found, the loop terminates, and `name` is assigned to the instance variable `username`.

<answer>
public Account(String requestedName)
{
    String name = requestedName;
    int count = 1;
    while (!isAvailable(name))
    {
        name = requestedName + count;
        count++;
    }
    username = name;
}
</answer>
