# Attempt 1 (Baseline - Correct Submission)

This is my original, correct submission. The constructor first checks if the requested name is available. If so, it's used directly. Otherwise, it iterates through suffixes starting at 1, using `isAvailable` to test each candidate, until an available one is found.

<answer>
public Account(String requestedName)
{
    if (isAvailable(requestedName))
    {
        username = requestedName;
    }
    else
    {
        int suffix = 1;
        while (!isAvailable(requestedName + suffix))
        {
            suffix++;
        }
        username = requestedName + suffix;
    }
}
</answer>
