### Part A

**Explanation:**

The `Account` constructor is designed to find an available username and assign it to the `username` instance variable. The logic proceeds as follows:

1.  It initializes a `currentName` variable with the `requestedName`.
2.  A `while` loop is used to check if `currentName` is available by calling the static helper method `isAvailable`.
3.  If `isAvailable(currentName)` returns `false`, the loop body executes. Inside the loop, a new `currentName` is generated by appending an integer (which starts at 1 and increments on each iteration) to the original `requestedName`.
4.  This process repeats, checking "requestedName1", "requestedName2", and so on, until `isAvailable` returns `true`.
5.  If the initial `requestedName` is available, the `while` loop's condition is immediately false, and the loop is skipped.
6.  Once the loop terminates (either by finding an available name with an appended number or by skipping entirely), the final available `currentName` is assigned to the `this.username` instance variable.

<answer>
public Account(String requestedName)
{
    String currentName = requestedName;
    int num = 1;
    while (!isAvailable(currentName))
    {
        currentName = requestedName + num;
        num++;
    }
    this.username = currentName;
}
</answer>

### Part B

**Explanation:**

The `getShortenedName` method creates and returns a modified version of the `username` without altering the original instance variable. The goal is to remove every hyphen and the single character immediately preceding it.

1.  The implementation uses a `while` loop and the `indexOf` method to repeatedly find the position of the next hyphen ("-") in the `username`.
2.  It builds the shortened name piece by piece in a `result` string.
3.  In each iteration, it finds the `hyphenIndex`.
    *   If a hyphen is found (`hyphenIndex != -1`), it means a segment of the username needs to be processed. The code appends the substring from the last processed position (`currentIndex`) up to, but not including, the character before the hyphen (`hyphenIndex - 1`). The `currentIndex` is then updated to the position immediately after the hyphen (`hyphenIndex + 1`) for the next search.
    *   If no more hyphens are found (`hyphenIndex == -1`), the remainder of the `username` from the `currentIndex` to the end is appended to the `result`, and the loop terminates.
4.  The final `result` string, now containing the shortened name, is returned.

<answer>
public String getShortenedName()
{
    String result = "";
    int currentIndex = 0;
    while (currentIndex < username.length())
    {
        int hyphenIndex = username.indexOf("-", currentIndex);
        if (hyphenIndex == -1)
        {
            result += username.substring(currentIndex);
            break;
        }
        else
        {
            result += username.substring(currentIndex, hyphenIndex - 1);
            currentIndex = hyphenIndex + 1;
        }
    }
    return result;
}
</answer>
