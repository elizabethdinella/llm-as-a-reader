The constructor must initialize the `username` field based on the availability rules. It begins by tentatively assigning `requestedName`. It then repeatedly tests availability (via the given helper) and, when necessary, rewrites the candidate by appending the next integer suffix until an unused name is obtained.

```java
public Account(String requestedName)
{
    username = requestedName;
    int suffix = 1;
    while (!isAvailable(username))
    {
        username = requestedName + suffix;
        suffix++;
    }
}
```

The `getShortenedName` method must produce a new string in which every hyphen together with the character that immediately precedes it has been deleted, while leaving the original `username` field unchanged. A single left-to-right scan accomplishes this: whenever the character after the current index is a hyphen, both characters are skipped; otherwise the current character is copied into the result.

```java
public String getShortenedName()
{
    String result = "";
    int i = 0;
    while (i < username.length())
    {
        if (i + 1 < username.length() && username.charAt(i + 1) == '-')
        {
            i += 2;          // drop char-before-hyphen and the hyphen
        }
        else
        {
            result += username.charAt(i);
            i++;
        }
    }
    return result;
}
```
