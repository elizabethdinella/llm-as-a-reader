## Attempt 1 (Correct Solution)

Let me trace through the requirements carefully. The constructor fills the bottle to capacity. The `updateAmount` method subtracts the used amount, checks if the result is below 25% of capacity, and if so resets to capacity.

Let me verify with the table: `updateAmount(300.0)` on 500 gives 200, which is less than 250 (25% of 1000), so it resets to 1000.0. ✓

<answer>
public class Bottle
{
    private double capacity;
    private double amount;

    public Bottle(double cap)
    {
        capacity = cap;
        amount = cap;
    }

    public double updateAmount(double used)
    {
        amount = amount - used;
        if (amount < 0.25 * capacity)
        {
            amount = capacity;
        }
        return amount;
    }
}
</answer>
