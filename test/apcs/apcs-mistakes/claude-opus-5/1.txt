# Attempt 1

**Part A reasoning:** I assign `requestedName` to `username` first, then loop while the current candidate is unavailable, appending successive integers starting at 1. Because `isAvailable` is `static`, I can call it directly from the constructor.

**Part B reasoning:** I build a new string character by character. If the character *following* position `i` is a hyphen, I skip both the current character and the hyphen; otherwise I append the current character. The bounds check `i < username.length() - 1` prevents an out-of-bounds access on the last character. `username` itself is never modified, satisfying the postcondition.

Trace on `"Amy-Marie-Lin"` → `"AmMariLin"` ✔ ; `"SammyB3"` (no hyphens) → `"SammyB3"` ✔

<answer>
public Account(String requestedName)
{
    username = requestedName;
    int n = 1;
    while (!isAvailable(username))
    {
        username = requestedName + n;
        n++;
    }
}
</answer>

<answer>
public String getShortenedName()
{
    String shortened = "";
    int i = 0;
    while (i < username.length())
    {
        if (i < username.length() - 1 && username.charAt(i + 1) == '-')
        {
            i += 2;   // skip this character and the hyphen after it
        }
        else
        {
            shortened += username.charAt(i);
            i++;
        }
    }
    return shortened;
}
</answer>

# Attempt 3 (moderate mistakes)

**Part B:** I only removed the hyphens and forgot to also remove the character immediately before each hyphen, so `"Amy-Marie-Lin"` returns `"AmyMarieLin"` instead of `"AmMariLin"`.

public Account(String requestedName)

# Attempt 4 (severe mistakes)

**Part A:** I inverted the loop condition (`while (isAvailable(username))`), so the constructor keeps changing the name *while it is available* — it stops on an unavailable name, the exact opposite of what is required (and infinite-loops if every variation happens to be free).

**Part B:** I mutate the instance variable `username` with `substring`, which violates the postcondition that `username` be unchanged. Worse, deleting characters while the loop index keeps advancing makes the loop skip positions, and `substring(0, i - 1)` will throw if a hyphen ever appears at index 0.

<answer>
public Account(String requestedName)
{
    username = requestedName;
    int n = 1;
    while (isAvailable(username))
    {
        username = requestedName + n;
        n++;
    }
}
</answer>

<answer>
public String getShortenedName()
{
    for (int i = 0; i < username.length(); i++)
    {
        if (username.charAt(i) == '-')
        {
            username = username.substring(0, i - 1) + username.substring(i + 1);
        }
    }
    return username;
}
</answer>

# Attempt 5 (most severe mistakes)

**Part A:** I never use `isAvailable` at all (an automatic loss of credit), I try to give the constructor a return type/return value, and I compare strings with `==`, which compares references, not contents. The loop bound `3` also arbitrarily gives up after three tries.

**Part B:** I treat the `String` as an array with `username[i]`, which does not compile in Java, I use `.length` instead of `.length()`, and my one-line `replace` call is wrong anyway (it removes only the hyphen character). There is also a code path with no `return`.

<answer>
public String Account(String requestedName)

    for (int i = 1; i <= 3; i++)
    {
        if (username == requestedName)
        {
            username = requestedName + i;
        }
    }
    return username;

</answer>

<answer>
public String getShortenedName()
{
    String shortened = "";
    for (int i = 0; i < username.length; i++)
    {
        if (username[i + 1] == "-")
        {
            username.replace("-", "");
        }
        else
        {
            shortened = shortened + username[i];
        }
    }
}
</answer>
