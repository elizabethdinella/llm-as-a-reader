## Attempt 1

I loop through every history record and search the math list for a record with the same student ID. If I find one, that student is enrolled in both courses, so I compare the absence counts and increment the counter when the history absences are at least as large. Since no ID is repeated, I can stop searching the math list as soon as I find the match.

<answer>
public int moreHistoryThanMathAbsences()
{
    int count = 0;
    for (CourseRecord hist : historyList)
    {
        for (CourseRecord math : mathList)
        {
            if (hist.getStudentID().equals(math.getStudentID()))
            {
                if (hist.getAbsences() >= math.getAbsences())
                {
                    count++;
                }
                break;
            }
        }
    }
    return count;
}

## Attempt 4

Instead of nested loops I walk through the lists with a single index, pulling out one record from each list at a time. If the two records belong to the same student, I compare their absences and add one to the counter when the history course has more.

<answer>
public int moreHistoryThanMathAbsences()
{
    int count = 0;
    for (int i = 0; i < mathList.size(); i++)
    {
        CourseRecord hist = historyList.get(i);
        CourseRecord math = mathList.get(i);
        if (hist.getStudentID().equals(math.getStudentID()))
        {
            if (hist.getAbsences() > math.getAbsences())
            {
                count++;
            }
        }
    }
    return count;
}
</answer>

## Attempt 5

I use indexed loops over both lists and compare the student IDs directly. When the IDs match, I compare the absence values stored in each record and increment my counter if the history value is larger, then stop the inner search.

<answer>
public int moreHistoryThanMathAbsences()
{
    int count = 0;
    for (int i = 0; i < historyList.length; i++)
    {
        for (int j = 0; j < mathList.length; j++)
        {
            if (historyList[i].studentID == mathList[j].studentID)
            {
                if (historyList[i].absences > mathList[j].absences)
                {
                    count++;
                }
                break;
            }
        }
    }
    return count;
}
</answer>
