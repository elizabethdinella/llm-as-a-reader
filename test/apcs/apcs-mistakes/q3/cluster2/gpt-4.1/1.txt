### Exam Attempt 1 (Correct)

**Explanation:**  
- I build a map from studentID to math absences for O(1) lookup for each history student.
- I iterate each history record, check for overlap, and count if history absences are greater than math absences.

```java
<answer>
public int moreHistoryThanMathAbsences() {
    int count = 0;
    HashMap<String, Integer> mathAbsencesMap = new HashMap<>();
    for (CourseRecord cr : mathList) {
        mathAbsencesMap.put(cr.getStudentID(), cr.getAbsences());
    }
    for (CourseRecord cr : historyList) {
        String id = cr.getStudentID();
        if (mathAbsencesMap.containsKey(id)) {
            int historyAbs = cr.getAbsences();
            int mathAbs = mathAbsencesMap.get(id);
            if (historyAbs > mathAbs) {
                count++;
            }
        }
    }
    return count;
}
</answer>
```

### Exam Attempt 4 (Serious Mistake: Forget to Check Overlap)

**Explanation:**  
- Count all students in historyList with more absences than same index in mathList, even if not the same student, and do not check if student is enrolled in both.

```java
<answer>
public int moreHistoryThanMathAbsences() {
    int count = 0;
    for (int i = 0; i < historyList.size() && i < mathList.size(); i++) {
        if (historyList.get(i).getAbsences() > mathList.get(i).getAbsences()) {
            count++;
        }
    }
    return count;
}
</answer>
```

### Exam Attempt 5 (Very Severe Mistake: No Absence Checks, Only Overlap Counts)

**Explanation:**  
- Only count how many student IDs are in both lists, ignore absences entirely.

```java
<answer>
public int moreHistoryThanMathAbsences() {
    int count = 0;
    HashSet<String> mathStudents = new HashSet<>();
    for (CourseRecord cr : mathList) {
        mathStudents.add(cr.getStudentID());
    }
    for (CourseRecord cr : historyList) {
        if (mathStudents.contains(cr.getStudentID())) {
            count++;
        }
    }
    return count;
```
