public class Bird

        YPosition = 500.0;

<answer>
public String GetPosition()

**(a)(iv)** A local variable holds the distance; a selection statement (I used `switch` on the `char`) decides which attribute is changed and whether it increases or decreases. Note the `60.0` so real division is used.

<answer>
public void Move(char Direction, int MinutesFlying)
{
    double DistanceTravelled = (DistancePerHour / 60.0) * MinutesFlying;

    switch (Direction)
    {
        case 'N':
            YPosition = YPosition + DistanceTravelled;
            break;
        case 'S':
            YPosition = YPosition - DistanceTravelled;
            break;
        case 'E':
            XPosition = XPosition + DistanceTravelled;
            break;
        case 'W':
            XPosition = XPosition - DistanceTravelled;
            break;
    }
}
</answer>

**(c)(i)** Each input is inside its own post-condition loop so it repeats until valid: bird must be 1 or 2, direction must be N/S/E/W, minutes must be 0–500. `hasNextInt()` guards against non-numeric input.

<answer>
import java.util.Scanner;

public class Main
{
    public static void main(String[] args)
    {
        Scanner Input = new Scanner(System.in);

        Bird Bird1 = new Bird("Cockatiel", 71.0);
        Bird Bird2 = new Bird("Macaw", 56.0);

        System.out.println("Bird 1 is a " + Bird1.GetSpecies() + " at position " + Bird1.GetPosition());
        System.out.println("Bird 2 is a " + Bird2.GetSpecies() + " at position " + Bird2.GetPosition());

        int Choice = 0;
        do
        {
            System.out.println("Enter the bird you want to move (1 or 2):");
            while (!Input.hasNextInt())
            {
                System.out.println("Please enter the number 1 or 2:");
                Input.next();
            }
            Choice = Input.nextInt();
        } while (Choice != 1 && Choice != 2);

        char Direction = ' ';
        boolean ValidDirection = false;
        do
        {
            System.out.println("Enter the direction of travel (N, S, E or W):");
            String DirectionInput = Input.next().toUpperCase();
            if (DirectionInput.length() == 1 &&
               (DirectionInput.charAt(0) == 'N' || DirectionInput.charAt(0) == 'S' ||
                DirectionInput.charAt(0) == 'E' || DirectionInput.charAt(0) == 'W'))
            {
                Direction = DirectionInput.charAt(0);
                ValidDirection = true;
            }
            else
            {
                System.out.println("Invalid direction entered.");
            }
        } while (ValidDirection == false);

        int Minutes = -1;
        do
        {
            System.out.println("Enter the number of minutes flown (0 to 500):");
            while (!Input.hasNextInt())
            {
                System.out.println("Please enter a whole number between 0 and 500:");
                Input.next();
            }
            Minutes = Input.nextInt();
            if (Minutes < 0 || Minutes > 500)
            {
                System.out.println("Minutes must be between 0 and 500.");
            }
        } while (Minutes < 0 || Minutes > 500);

        if (Choice == 1)
        {
            Bird1.Move(Direction, Minutes);
            System.out.println("The " + Bird1.GetSpecies() + " has moved. New position: " + Bird1.GetPosition());
        }
        else
        {
            Bird2.Move(Direction, Minutes);
            System.out.println("The " + Bird2.GetSpecies() + " has moved. New position: " + Bird2.GetPosition());
        }
    }
}
</answer>
