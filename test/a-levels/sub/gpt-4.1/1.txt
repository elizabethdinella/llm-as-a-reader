### (a)(iv) `Move()` method.

**Explanation:**  
- Parameters: direction ('N', 'S', 'E', 'W'), and number of minutes flying (int).
- distance = (distancePerHour / 60) * minutes
- Update XPosition or YPosition according to direction.

```java
public void Move(char direction, int minutes) {
    double distance = (this.DistancePerHour / 60.0) * minutes;
    switch (direction) {
        case 'N': this.YPosition += distance; break;
        case 'S': this.YPosition -= distance; break;
        case 'E': this.XPosition += distance; break;
        case 'W': this.XPosition -= distance; break;
    }
}
```

### (c)(i) Main program with user interaction and input validation.

**Explanation:**  
- Output both birds' species and positions.
- Prompt the user to select (1 or 2) — repeat until user enters a valid value.
- Prompt for direction (must be 'N', 'S', 'E', 'W') — repeat until valid.
- Prompt for minutes (0 to 500) — repeat until valid.
- Call the `Move` method for selected bird; output new position.

Here is code using `Scanner` for input:

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Bird bird1 = new Bird("Cockatiel", 71.0);
        Bird bird2 = new Bird("Macaw", 56.0);

        Scanner scanner = new Scanner(System.in);

        // Output birds' information
        System.out.println("Bird 1: " + bird1.GetSpecies() + ", " + bird1.GetPosition());
        System.out.println("Bird 2: " + bird2.GetSpecies() + ", " + bird2.GetPosition());

        // Select bird
        int birdNum = 0;
        while (birdNum != 1 && birdNum != 2) {
            System.out.print("Enter the number of the bird to move (1 for Cockatiel, 2 for Macaw): ");
            if (scanner.hasNextInt()) {
                birdNum = scanner.nextInt();
            } else {
                scanner.next(); // clear invalid input
            }
        }

        // Input direction
        char direction = ' ';
        boolean validDir = false;
        while (!validDir) {
            System.out.print("Enter direction (N/S/E/W): ");
            String dirInput = scanner.next();
            dirInput = dirInput.toUpperCase();
            if (dirInput.length() == 1 &&
                (dirInput.charAt(0) == 'N' ||
                 dirInput.charAt(0) == 'S' ||
                 dirInput.charAt(0) == 'E' ||
                 dirInput.charAt(0) == 'W')) {
                direction = dirInput.charAt(0);
                validDir = true;
            }
        }

        // Input minutes
        int minutes = -1;
        while (minutes < 0 || minutes > 500) {
            System.out.print("Enter minutes flying (0-500): ");
            if (scanner.hasNextInt()) {
                minutes = scanner.nextInt();
            } else {
                scanner.next();
            }
        }

        // Move the chosen bird and output new position
        Bird chosenBird = (birdNum == 1) ? bird1 : bird2;
        chosenBird.Move(direction, minutes);
        System.out.println("After moving:");
        System.out.println(chosenBird.GetSpecies() + ": " + chosenBird.GetPosition());

        scanner.close();
    }
}
```
