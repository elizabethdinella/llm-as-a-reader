## (a)(i) Class declaration and constructor

All four attributes are `private` (encapsulation). The constructor takes the species and speed as parameters and sets both positions to 500.0.

**Explanation:** `DistancePerHour`, `XPosition`, `YPosition` are real numbers so they are `double`; `Species` is a `String`. `XPosition`/`YPosition` are *not* parameters – they are hard-coded to 500.0 as stated in the design.

<answer>
public class Bird
{
    private double DistancePerHour;
    private String Species;
    private double XPosition;
    private double YPosition;

    public Bird(String NewSpecies, double NewDistancePerHour)
    {
        Species = NewSpecies;
        DistancePerHour = NewDistancePerHour;
        XPosition = 500.0;
        YPosition = 500.0;
    }
}
</answer>

## (a)(ii) GetSpecies()

**Explanation:** A public "get" (accessor) method with return type `String`, no parameters, that returns the private attribute.

<answer>
public String GetSpecies()
{
    return Species;
}
</answer>

## (a)(iii) GetPosition()

**Explanation:** The method returns a `String`, so the two `double` values are concatenated with the literal text using `+`. Java automatically converts the doubles to text, e.g. `X = 500.0 Y = 250.0`.

<answer>
public String GetPosition()
{
    return "X = " + XPosition + " Y = " + YPosition;
}
</answer>

## (a)(iv) Move()

**Explanation:** Parameters are a `char` (direction) and an `int` (minutes). The distance is calculated once with the given formula, then a `switch` (or nested if) selects which attribute to increase/decrease: N adds to Y, S subtracts from Y, E adds to X, W subtracts from X. No return value, so `void`. No validation is required.

<answer>
public void Move(char Direction, int MinutesFlying)
{
    double DistanceTravelled;
    DistanceTravelled = (DistancePerHour / 60) * MinutesFlying;

    switch (Direction)
    {
        case 'N':
            YPosition = YPosition + DistanceTravelled;
            break;
        case 'S':
            YPosition = YPosition - DistanceTravelled;
            break;
        case 'E':
            XPosition = XPosition + DistanceTravelled;
            break;
        case 'W':
            XPosition = XPosition - DistanceTravelled;
            break;
    }
}
</answer>

## (c)(i) Main program

**Explanation:** A `Scanner` is used for the three inputs. Each input is inside a post-conditioned loop (`do … while`) so it repeats until the data is valid: the bird choice must be 1 or 2, the direction must be `N`, `S`, `E` or `W` (converted to upper case so lower-case input is accepted), and the minutes must be between 0 and 500 inclusive. `hasNextInt()` guards against non-numeric input. The chosen object's `Move()` method is then called and `GetPosition()`/`GetSpecies()` are used for the meaningful output before and after the move.

<answer>
import java.util.Scanner;

public class BirdProgram
{
    public static void main(String[] args)
    {
        Scanner Input = new Scanner(System.in);

        Bird Bird1 = new Bird("Cockatiel", 71.0);
        Bird Bird2 = new Bird("Macaw", 56.0);

        // output current data for both birds
        System.out.println("Bird 1 is a " + Bird1.GetSpecies() + " at position " + Bird1.GetPosition());
        System.out.println("Bird 2 is a " + Bird2.GetSpecies() + " at position " + Bird2.GetPosition());

        // input and validate which bird to move
        int Choice;
        do
        {
            System.out.println("Enter 1 to move the " + Bird1.GetSpecies()
                             + " or 2 to move the " + Bird2.GetSpecies() + ":");
            while (!Input.hasNextInt())
            {
                System.out.println("Invalid input. Please enter 1 or 2:");
                Input.next();
            }
            Choice = Input.nextInt();
            if (Choice != 1 && Choice != 2)
            {
                System.out.println("Invalid choice, you must enter 1 or 2.");
            }
        } while (Choice != 1 && Choice != 2);

        // input and validate the direction
        char Direction;
        do
        {
            System.out.println("Enter the direction of travel (N, S, E or W):");
            Direction = Character.toUpperCase(Input.next().charAt(0));
            if (Direction != 'N' && Direction != 'S' && Direction != 'E' && Direction != 'W')
            {
                System.out.println("Invalid direction, you must enter N, S, E or W.");
            }
        } while (Direction != 'N' && Direction != 'S' && Direction != 'E' && Direction != 'W');

        // input and validate the number of minutes
        int Minutes;
        do
        {
            System.out.println("Enter the number of minutes flying (0 to 500):");
            while (!Input.hasNextInt())
            {
                System.out.println("Invalid input. Please enter a whole number between 0 and 500:");
                Input.next();
            }
            Minutes = Input.nextInt();
            if (Minutes < 0 || Minutes > 500)
            {
                System.out.println("Invalid time, it must be between 0 and 500 minutes.");
            }
        } while (Minutes < 0 || Minutes > 500);

        // move the chosen bird and output its new position
        if (Choice == 1)
        {
            Bird1.Move(Direction, Minutes);
            System.out.println("The " + Bird1.GetSpecies() + " has moved to " + Bird1.GetPosition());
        }
        else
        {
            Bird2.Move(Direction, Minutes);
            System.out.println("The " + Bird2.GetSpecies() + " has moved to " + Bird2.GetPosition());
        }
    }
}
</answer>
