public class Bird {
    private double distancePerHour;   // km/h, 0.0 – 100.0
    private String species;
    private double xPosition;
    private double yPosition;

    public Bird(String species, double distancePerHour) {
        this.species = species;
        this.distancePerHour = distancePerHour;
        this.xPosition = 500.0;
        this.yPosition = 500.0;
    }
}

**(a)(iv) – `Move()` method**

Computes the travelled distance from *distancePerHour* and the supplied minutes, then updates the appropriate coordinate according to the direction character.

<answer>
public void Move(char direction, int minutes) {
    double distanceTravelled = (distancePerHour / 60.0) * minutes; // km

    switch (Character.toUpperCase(direction)) {
        case 'N':
            yPosition += distanceTravelled;
            break;
        case 'S':
            yPosition -= distanceTravelled;
            break;
        case 'E':
            xPosition += distanceTravelled;
            break;
        case 'W':
            xPosition -= distanceTravelled;
            break;
        // No validation required – assume caller passes a correct value
    }
}
</answer>

**(c)(i) – Full code to amend the `main` program**

The snippet prints the initial data, repeatedly asks for a valid bird choice, direction and minutes, calls `Move`, and finally shows the updated position. All input is validated as required.

<answer>
import java.util.Scanner;

public class BirdDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // create the birds
        Bird cockatiel = new Bird("Cockatiel", 71.0);
        Bird macaw     = new Bird("Macaw",      56.0);

        // show initial positions
        System.out.println("Current bird data:");
        System.out.println(cockatiel.GetSpecies() + " – " + cockatiel.GetPosition());
        System.out.println(macaw.GetSpecies()   + " – " + macaw.GetPosition());

        // ----- choose a bird -------------------------------------------------
        Bird chosen = null;
        while (chosen == null) {
            System.out.print("Select a bird to move (1 = Cockatiel, 2 = Macaw): ");
            String sel = sc.nextLine().trim();
            if (sel.equals("1")) {
                chosen = cockatiel;
            } else if (sel.equals("2")) {
                chosen = macaw;
            } else {
                System.out.println("Invalid selection. Please enter 1 or 2.");
            }
        }

        // ----- choose a direction --------------------------------------------
        char direction = ' ';
        while (true) {
            System.out.print("Enter travel direction (N, S, E or W): ");
            String dirInput = sc.nextLine().trim().toUpperCase();
            if (dirInput.length() == 1 && "NSEW".contains(dirInput)) {
                direction = dirInput.charAt(0);
                break;
            } else {
                System.out.println("Invalid direction. Use N, S, E or W.");
            }
        }

        // ----- enter minutes --------------------------------------------------
        int minutes = -1;
        while (true) {
            System.out.print("Enter flying time in minutes (0‑500): ");
            String minInput = sc.nextLine().trim();
            try {
                minutes = Integer.parseInt(minInput);
                if (minutes >= 0 && minutes <= 500) {
                    break;
                } else {
                    System.out.println("Minutes must be between 0 and 500.");
                }
            } catch (NumberFormatException e) {
                System.out.println("Please enter a valid integer number of minutes.");
            }
        }

        // ----- move the bird --------------------------------------------------
        chosen.Move(direction, minutes);

        // ----- show updated position -----------------------------------------
        System.out.println("After moving, " + chosen.GetSpecies() +
                           " is now at: " + chosen.GetPosition());

        sc.close();
    }
}
</answer>
