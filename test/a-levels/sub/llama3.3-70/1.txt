### (a)(iv) Implementing the Move() method
This method updates the bird's position based on the direction and time of travel.

```java
public void move(char direction, int minutesFlying) {
    double distanceTravelled = (distancePerHour / 60) * minutesFlying;
    
    switch (direction) {
        case 'N':
            yPosition += distanceTravelled;
            break;
        case 'S':
            yPosition -= distanceTravelled;
            break;
        case 'E':
            xPosition += distanceTravelled;
            break;
        case 'W':
            xPosition -= distanceTravelled;
            break;
    }
}
```

### (c)(i) Amending the main program to update bird positions
The program will output the birds' current positions, prompt the user to select a bird and enter direction and travel time, update the chosen bird's position, and display the updated position.

```java
import java.util.InputMismatchException;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Bird cockatiel = new Bird(71.0, "Cockatiel");
        Bird macaw = new Bird(56.0, "Macaw");
        
        Scanner scanner = new Scanner(System.in);
        boolean validInput = false;
        int birdChoice = 0;
        char direction = ' ';
        int travelTime = 0;

        System.out.println("Current positions:");
        System.out.println(cockatiel.getSpecies() + ": " + cockatiel.getPosition());
        System.out.println(macaw.getSpecies() + ": " + macaw.getPosition());

        while (!validInput) {
            try {
                System.out.print("Enter the number of the bird to move (1 for Cockatiel, 2 for Macaw): ");
                birdChoice = scanner.nextInt();
                if (birdChoice != 1 && birdChoice != 2) {
                    System.out.println("Invalid choice. Please enter 1 or 2.");
                } else {
                    validInput = true;
                }
            } catch (InputMismatchException e) {
                System.out.println("Invalid input. Please enter a number.");
                scanner.next(); // Clear the invalid input
            }
        }

        validInput = false;
        while (!validInput) {
            try {
                System.out.print("Enter the direction of travel (N, S, E, W): ");
                direction = scanner.next().charAt(0);
                if (direction != 'N' && direction != 'S' && direction != 'E' && direction != 'W') {
                    System.out.println("Invalid direction. Please enter N, S, E, or W.");
                } else {
                    validInput = true;
                }
            } catch (Exception e) {
                System.out.println("Invalid input. Please try again.");
                scanner.next(); // Clear the invalid input
            }
        }

        validInput = false;
        while (!validInput) {
            try {
                System.out.print("Enter the travel time in minutes: ");
                travelTime = scanner.nextInt();
                if (travelTime < 0 || travelTime > 500) {
                    System.out.println("Invalid travel time. Please enter a value between 0 and 500.");
                } else {
                    validInput = true;
                }
            } catch (InputMismatchException e) {
                System.out.println("Invalid input. Please enter a number.");
                scanner.next(); // Clear the invalid input
            }
        }

        if (birdChoice == 1) {
            cockatiel.move(direction, travelTime);
            System.out.println("Updated position of " + cockatiel.getSpecies() + ": " + cockatiel.getPosition());
        } else {
            macaw.move(direction, travelTime);
            System.out.println("Updated position of " + macaw.getSpecies() + ": " + macaw.getPosition());
        }
    }
}
```
