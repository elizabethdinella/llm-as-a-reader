(a)(i) Declare the class Bird with private attributes and a constructor
Explanation:
- Uses double for Real and String for Species.
- All attributes are private.
- Constructor sets Species and DistancePerHour from parameters and initializes both XPosition and YPosition to 500.0.

<answer>
public class Bird {
    private double DistancePerHour;
    private String Species;
    private double XPosition;
    private double YPosition;

    public Bird(String species, double distancePerHour) {
        this.Species = species;
        this.DistancePerHour = distancePerHour;
        this.XPosition = 500.0;
        this.YPosition = 500.0;
    }
}

(a)(iv) Method Move(direction, minutes)
Explanation:
- Computes distance = (DistancePerHour / 60) * minutes.
- Updates X or Y based on direction. No validation (as specified).

<answer>
public void Move(char direction, int minutes) {
    double distance = (this.DistancePerHour / 60.0) * minutes;
    switch (Character.toUpperCase(direction)) {
        case 'N':
            this.YPosition += distance;
            break;
        case 'S':
            this.YPosition -= distance;
            break;
        case 'E':
            this.XPosition += distance;
            break;
        case 'W':
            this.XPosition -= distance;
            break;
        default:
            // No validation required per specification
            break;
    }
}
</answer>

(c)(i) Amend the main program to interact with the user, validate inputs, move the chosen bird, and report the new position
Explanation:
- Prints each bird’s species and current position.
- Repeats input until valid for: bird selection (1 or 2), direction (N/S/E/W), and minutes (0–500).
- Calls Move and then prints the updated position.

<answer>
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        Bird bird1 = new Bird("Cockatiel", 71.0);
        Bird bird2 = new Bird("Macaw", 56.0);

        System.out.println("Current birds and positions:");
        System.out.println("1) " + bird1.GetSpecies() + " - " + bird1.GetPosition());
        System.out.println("2) " + bird2.GetSpecies() + " - " + bird2.GetPosition());

        int selection;
        while (true) {
            System.out.print("Select a bird to move (enter 1 for " + bird1.GetSpecies() + " or 2 for " + bird2.GetSpecies() + "): ");
            String line = sc.nextLine().trim();
            try {
                selection = Integer.parseInt(line);
                if (selection == 1 || selection == 2) {
                    break;
                }
            } catch (NumberFormatException e) {
                // fall through to invalid message
            }
            System.out.println("Invalid selection. Please enter 1 or 2.");
        }

        Bird chosen = (selection == 1) ? bird1 : bird2;

        char dir;
        while (true) {
            System.out.print("Enter direction (N for north, S for south, E for east, W for west): ");
            String s = sc.nextLine().trim().toUpperCase();
            if (s.length() == 1 && "NSEW".indexOf(s.charAt(0)) >= 0) {
                dir = s.charAt(0);
                break;
            }
            System.out.println("Invalid direction. Please enter N, S, E, or W.");
        }

        int minutes;
        while (true) {
            System.out.print("Enter minutes of flight (0 to 500 inclusive): ");
            String line = sc.nextLine().trim();
            try {
                minutes = Integer.parseInt(line);
                if (minutes >= 0 && minutes <= 500) {
                    break;
                }
            } catch (NumberFormatException e) {
                // fall through to invalid message
            }
            System.out.println("Invalid input. Please enter an integer from 0 to 500.");
        }

        chosen.Move(dir, minutes);

        System.out.println("Updated position for " + chosen.GetSpecies() + ": " + chosen.GetPosition());

        sc.close();
    }
}
</answer>
