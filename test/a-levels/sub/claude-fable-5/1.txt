# Question 1 Solutions

## (a)(i) — Class declaration and constructor

The class needs four private attributes. The constructor takes the species and distance per hour as parameters, and initialises both position attributes to 500.0.

**Explanation:** Attributes are marked `private` for encapsulation. The constructor uses `this.` to distinguish attributes from parameters. `double` is used for Real values.

<answer>
public class Bird {
    private double distancePerHour;
    private String species;
    private double xPosition;
    private double yPosition;

    public Bird(String species, double distancePerHour) {
        this.species = species;
        this.distancePerHour = distancePerHour;
        this.xPosition = 500.0;
        this.yPosition = 500.0;
    }
}
</answer>

## (a)(ii) — GetSpecies()

**Explanation:** A simple accessor (getter) method that returns the private `species` attribute as a `String`.

<answer>
public String getSpecies() {
    return species;
}
</answer>

## (a)(iii) — GetPosition()

**Explanation:** The method concatenates the literals `"X = "` and `" Y = "` with the two position attributes. Java automatically converts the `double` values to their string representation (e.g., `500.0`), producing output like `X = 500.0 Y = 250.0`.

<answer>
public String getPosition() {
    return "X = " + xPosition + " Y = " + yPosition;
}
</answer>

## (a)(iv) — Move()

**Explanation:** The method takes a `char` for direction and an `int` for minutes. It first calculates the distance using the given formula, then uses a switch (or if/else) to update the correct attribute: N adds to Y, S subtracts from Y, E adds to X, W subtracts from X.

<answer>
public void move(char direction, int minutes) {
    double distance = (distancePerHour / 60) * minutes;
    switch (direction) {
        case 'N':
            yPosition = yPosition + distance;
            break;
        case 'S':
            yPosition = yPosition - distance;
            break;
        case 'E':
            xPosition = xPosition + distance;
            break;
        case 'W':
            xPosition = xPosition - distance;
            break;
    }
}
</answer>

## (c)(i) — Main program

**Explanation:** The program:
1. Outputs each bird's species and position using `getSpecies()` and `getPosition()`.
2. Uses a `do-while` validation loop for the bird choice (must be 1 or 2).
3. Uses a `do-while` validation loop for direction (must be N, S, E or W — I also convert to uppercase for robustness).
4. Uses a `do-while` validation loop for minutes (must be 0–500 inclusive, as stated in the class definition).
5. Selects the chosen bird with a reference variable, calls `move()`, and outputs the updated position with a meaningful message.

<answer>
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        Bird bird1 = new Bird("Cockatiel", 71.0);
        Bird bird2 = new Bird("Macaw", 56.0);

        System.out.println("Bird 1: " + bird1.getSpecies() + " is at position " + bird1.getPosition());
        System.out.println("Bird 2: " + bird2.getSpecies() + " is at position " + bird2.getPosition());

        int choice;
        do {
            System.out.println("Which bird do you want to move? Enter 1 or 2:");
            choice = scanner.nextInt();
        } while (choice != 1 && choice != 2);

        char direction;
        do {
            System.out.println("Enter the direction of travel (N, S, E or W):");
            direction = scanner.next().toUpperCase().charAt(0);
        } while (direction != 'N' && direction != 'S' && direction != 'E' && direction != 'W');

        int minutes;
        do {
            System.out.println("Enter the number of minutes flying (0 to 500):");
            minutes = scanner.nextInt();
        } while (minutes < 0 || minutes > 500);

        Bird chosenBird;
        if (choice == 1) {
            chosenBird = bird1;
        } else {
            chosenBird = bird2;
        }

        chosenBird.move(direction, minutes);

        System.out.println("The " + chosenBird.getSpecies() + " has moved to new position: " + chosenBird.getPosition());
    }
}
</answer>
