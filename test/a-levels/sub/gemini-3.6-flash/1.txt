### (a)(i) Declare the `Bird` class and constructor

**Explanation:**
The class `Bird` requires four private attributes:
- `distancePerHour` (or `DistancePerHour`) of type `double`
- `species` (or `Species`) of type `String`
- `xPosition` (or `XPosition`) of type `double`
- `yPosition` (or `YPosition`) of type `double`

The constructor takes two parameters (`species` and `distancePerHour`) to initialize the corresponding attributes and sets both `xPosition` and `yPosition` to default values of `500.0`.

<answer>
public class Bird {
    private double distancePerHour;
    private String species;
    private double xPosition;
    private double yPosition;

    public Bird(String species, double distancePerHour) {
        this.species = species;
        this.distancePerHour = distancePerHour;
        this.xPosition = 500.0;
        this.yPosition = 500.0;
    }
}
</answer>

### (a)(iv) `Move()` Method

**Explanation:**
The `move` method takes a `char` direction ('N', 'S', 'E', or 'W') and an `int` representing minutes flown. It calculates the distance covered using `(distancePerHour / 60.0) * minutes` and updates either `xPosition` or `yPosition` depending on the direction:
- 'N': increase Y position
- 'S': decrease Y position
- 'E': increase X position
- 'W': decrease X position

<answer>
public void move(char direction, int minutes) {
    double distanceTravelled = (this.distancePerHour / 60.0) * minutes;
    
    switch (Character.toUpperCase(direction)) {
        case 'N':
            this.yPosition += distanceTravelled;
            break;
        case 'S':
            this.yPosition -= distanceTravelled;
            break;
        case 'E':
            this.xPosition += distanceTravelled;
            break;
        case 'W':
            this.xPosition -= distanceTravelled;
            break;
    }
}
</answer>

### (c)(i) Main program logic with input validation

**Explanation:**
The main program performs the following steps:
1. Outputs the species and position of both birds.
2. Prompts the user to pick bird 1 or bird 2, repeating until a valid selection is made.
3. Prompts the user for a valid direction ('N', 'S', 'E', 'W'), validating input with a loop.
4. Prompts the user for the flying time in minutes (0 to 500 inclusive), validating input with a loop.
5. Calls the `move` method on the selected bird and outputs its updated position.

<answer>
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Bird bird1 = new Bird("Cockatiel", 71.0);
        Bird bird2 = new Bird("Macaw", 56.0);

        System.out.println("Bird 1: " + bird1.getSpecies() + " | Position: " + bird1.getPosition());
        System.out.println("Bird 2: " + bird2.getSpecies() + " | Position: " + bird2.getPosition());

        Scanner scanner = new Scanner(System.in);

        int birdChoice = 0;
        while (birdChoice != 1 && birdChoice != 2) {
            System.out.print("Select bird to move (1 for " + bird1.getSpecies() + ", 2 for " + bird2.getSpecies() + "): ");
            if (scanner.hasNextInt()) {
                birdChoice = scanner.nextInt();
                if (birdChoice != 1 && birdChoice != 2) {
                    System.out.println("Invalid selection. Please enter 1 or 2.");
                }
            } else {
                System.out.println("Invalid input. Please enter a number.");
                scanner.next();
            }
        }

        char direction = ' ';
        while (direction != 'N' && direction != 'S' && direction != 'E' && direction != 'W') {
            System.out.print("Enter direction of travel (N, S, E, W): ");
            String input = scanner.next().toUpperCase();
            if (input.length() == 1) {
                char d = input.charAt(0);
                if (d == 'N' || d == 'S' || d == 'E' || d == 'W') {
                    direction = d;
                } else {
                    System.out.println("Invalid direction. Must be N, S, E, or W.");
                }
            } else {
                System.out.println("Invalid input. Enter a single character.");
            }
        }

        int minutes = -1;
        while (minutes < 0 || minutes > 500) {
            System.out.print("Enter time spent flying in minutes (0 to 500): ");
            if (scanner.hasNextInt()) {
                minutes = scanner.nextInt();
                if (minutes < 0 || minutes > 500) {
                    System.out.println("Invalid time. Minutes must be between 0 and 500.");
                }
            } else {
                System.out.println("Invalid input. Please enter an integer.");
                scanner.next();
            }
        }

        Bird selectedBird = (birdChoice == 1) ? bird1 : bird2;
        selectedBird.move(direction, minutes);

        System.out.println("Updated data for " + selectedBird.getSpecies() + ": " + selectedBird.getPosition());
    }
}
</answer>
