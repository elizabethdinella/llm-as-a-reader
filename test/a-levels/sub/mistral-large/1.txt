(a)(iv) The method `Move()` updates the bird's position based on the direction and time of travel:
```java
public void Move(char direction, int minutesFlying) {
    double distanceTravelled = (distancePerHour / 60) * minutesFlying;
    switch (direction) {
        case 'N':
            yPosition += distanceTravelled;
            break;
        case 'S':
            yPosition -= distanceTravelled;
            break;
        case 'E':
            xPosition += distanceTravelled;
            break;
        case 'W':
            xPosition -= distanceTravelled;
            break;
    }
}
```

(c)(i) To amend the main program to include user interaction and updates based on inputs:
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Bird cockatiel = new Bird("Cockatiel", 71.0);
        Bird macaw = new Bird("Macaw", 56.0);

        Scanner scanner = new Scanner(System.in);
        String birdChoice;
        char direction;
        int minutesFlying;

        do {
            System.out.println("Cockatiel: " + cockatiel.GetPosition());
            System.out.println("Macaw: " + macaw.GetPosition());

            System.out.print("Select a bird to move (Cockatiel or Macaw): ");
            birdChoice = scanner.nextLine();
        } while (!birdChoice.equalsIgnoreCase("Cockatiel") && !birdChoice.equalsIgnoreCase("Macaw"));

        do {
            System.out.print("Enter direction (N, S, E, W): ");
            direction = scanner.next().charAt(0);
        } while (direction != 'N' && direction != 'S' && direction != 'E' && direction != 'W');

        do {
            System.out.print("Enter time flying (minutes): ");
            minutesFlying = scanner.nextInt();
        } while (minutesFlying < 0 || minutesFlying > 500);

        if (birdChoice.equalsIgnoreCase("Cockatiel")) {
            cockatiel.Move(direction, minutesFlying);
            System.out.println("Cockatiel's new position: " + cockatiel.GetPosition());
        } else {
            macaw.Move(direction, minutesFlying);
            System.out.println("Macaw's new position: " + macaw.GetPosition());
        }
    }
}
```
